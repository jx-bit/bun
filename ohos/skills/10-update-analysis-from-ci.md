## Skill 10：从 CI 失败中更新分析文档

### 目的

每轮修复完成后，把新发现的问题、根因、解决方案更新回 issue 文档。

### 操作

1. **更新 issue 文档的"挑战"表格**：

```bash
# 在 p<优先级>-<问题>.md 的"挑战"表格里加新行
| <序号> | <问题> | <原因> | <解决方案> |
```

2. **更新修复时间线**：

```bash
# 在文档末尾加时间线
```

3. **如果是新问题（不是已有 issue 的子问题）**，创建新的 issue 文档

## 完整工作流示意

```
┌──────────────────────────────────────────────┐
│ Skill 1: 拉取四方代码仓库                     │
│   git fetch bun/hyq/ljy/origin               │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 2: 多仓库对比分析                       │
│   git diff + gh api compare                  │
│   → 识别差异文件和 OHOS 标记                  │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 3: 三方对比单个文件                     │
│   git diff + curl raw.githubusercontent.com  │
│   → 对每个差异文件，三方对比                   │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 4: 写 Issue 分析文档                    │
│   ohos/issues/pr<PR号>-p<N>-<keyword>.md       │
│   → 按优先级排序，逐个处理                     │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 5: 执行修复                             │
│   修改代码 → 验证 → 提交                      │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 6: 创建 PR                              │
│   gh pr create --base ohos-aarch64 --head dev│
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 7: 查看 PR 状态和 CI                    │
│   gh pr checks / gh run list / gh run view   │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 8: 拉取和分析 CI 失败日志               │
│   gh run view --log-failed | grep ...        │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 9: 修复循环（Fix-Verify Loop）          │
│   失败 → 分析 → 修复 → push → 再验证          │
│   (循环直到通过)                              │
└──────────────┬───────────────────────────────┘
               ↓
┌──────────────────────────────────────────────┐
│ Skill 10: 从 CI 失败中更新分析文档            │
│   更新 issue 文档 → 更新 tri-way 对比文档     │
└──────────────┬───────────────────────────────┘
               ↓
          下一个 issue → 回到 Skill 5
```
